# 🎓 Student Management System

A web-based Student Management System developed using **Java, Spring Boot, Spring Data JPA, Hibernate, MySQL and Thymeleaf**.

The application allows users to manage student information through a simple and user-friendly web interface.

---

## 🚀 Features

- 🔐 User Login
- 👨‍🎓 Add Student
- 📋 View All Students
- 🔍 Search Student by Name
- 🔎 Search Student by ID
- ✏️ Edit Student
- 🗑️ Delete Student
- 📷 Student Photo Upload
- 📧 Student Welcome Email
- 📊 Student Dashboard
- 📚 Course Statistics
- 🔢 Student Count
- 🔤 Sort Students
- 📄 Pagination
- 👤 Student Profile
